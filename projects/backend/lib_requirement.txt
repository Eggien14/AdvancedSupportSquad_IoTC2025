# =========================================
# TROUBLESHOOTING COMMON ISSUES
# =========================================
# 1. PyTorch CUDA conflict:
#    Solution: Uninstall torch and reinstall with --index-url for CPU-only
#
# 2. OpenCV import errors:
#    Solution: Use opencv-python-headless instead of opencv-python
#
# 3. MySQL connection issues:
#    Solution: Ensure PyMySQL version matches MySQL 8.0 authentication
#
# 4. FastAPI uvicorn startup issues:
#    Solution: Check if ports 8136/8100 are available
#
# 5. Ultralytics model download issues:
#    Solution: Pre-download models or check internet connectivity

# =========================================
# SECURITY CONSIDERATIONS
