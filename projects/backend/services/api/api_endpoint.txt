## [POST] /cart_inventory/{cart_id}/items
**Mục đích:** Cập nhật giỏ hàng với đồng bộ inventory tự động
**Đặc biệt:** Tự động xóa items có quantity=0, cập nhật kho product_master.quantity

### Mode 1: REPLACE - Thay thế toàn bộ giỏ hàng
**Request:**
POST /cart_inventory/142/items
Content-Type: application/json

```json
{
  "mode": "replace",
  "items": [
    {
      "product_id": 1,
      "quantity": 2
    },
    {
      "product_id": 6,
      "quantity": 1
    }
  ]
}
```

**Response:** 200 OK
```json
{
  "ok": true,
  "mode": "replace",
  "items_count": 2,
  "message": "Cart replaced successfully. Inventory updated."
}
```

### Mode 2: MERGE - Cập nhật từng phần, giữ nguyên items khác
**Request:**
POST /cart_inventory/142/items
Content-Type: application/json

```json
{
  "mode": "merge",
  "items": [
    {
      "product_id": 1,
      "quantity": 3
    }
  ]
}
```

**Response:** 200 OK
```json
{
  "ok": true,
  "mode": "merge",
  "items_count": 1,
  "message": "Cart merged successfully. Inventory updated."
}
```

### Mode 3: DELTA - Thay đổi theo số lượng +/-
**Request:**
POST /cart_inventory/142/items
Content-Type: application/json

```json
{
  "mode": "delta",
  "changes": [
    {
      "product_id": 1,
      "delta": -1
    },
    {
      "product_id": 3,
      "delta": 2
    }
  ]
}
```

**Response:** 200 OK
```json
{
  "ok": true,
  "mode": "delta",
  "items_count": 2,
  "message": "Cart delta applied successfully. Inventory updated."
}
```

**Error Responses:**
- 400 Bad Request: cart_id < 1, mode không hỗ trợ, product_id không tồn tại
- 422 Unprocessable Entity: Schema validation lỗi

# =========================================
# VII. LOGIC QUẢN LÝ KHO THÔNG MINH
# =========================================

## Replace Mode
1. Lấy tất cả items hiện tại trong cart
2. Tính delta: `old_quantity - new_quantity` 
3. Trả về kho: `inventory += delta_positive`
4. Lấy từ kho: `inventory -= delta_negative`
5. Thay thế toàn bộ cart bằng items mới

## Merge Mode  
1. Cập nhật từng product riêng lẻ
2. Tính delta: `old_cart_qty - new_cart_qty`
3. Cập nhật inventory tương ứng
4. Chỉ ảnh hưởng những products được specify

## Delta Mode (Đặc biệt)
1. Nếu `delta > 0`: Thêm vào cart, lấy từ kho `inventory -= delta`
2. Nếu `delta < 0`: Bỏ khỏi cart, nhưng chỉ trả về đúng số có trong cart
   - VD: Cart có 3, delta -4  chỉ trả về 3 vào kho, cart về 0
3. Inventory luôn `>= 0` (dùng `GREATEST(0, quantity + delta)`)

## Auto Cleanup
- Tự động xóa `cart_items` có `quantity = 0`
- Không để items "ma" trong database

# =========================================
# VIII. MÃ LỖI & TROUBLESHOOTING
# =========================================

## HTTP Status Codes
- **200 OK**: Thành công
- **400 Bad Request**: Tham số không hợp lệ, cart_id < 1, product_id không tồn tại
- **404 Not Found**: Không tìm thấy resource (product, cart, beacon)
- **422 Unprocessable Entity**: Schema validation lỗi (mode vs fields không khớp)
- **500 Internal Server Error**: Lỗi server, kiểm tra logs

## Common Issues
1. **CORS Error**: Bật CORS middleware trong server.py (development only)
2. **Database Connection**: Kiểm tra ENV variables và MySQL service
3. **Invalid UUID**: UUID phải đúng format v4 (36 characters với dashes)
4. **Inventory Mismatch**: Review delta calculation logic
