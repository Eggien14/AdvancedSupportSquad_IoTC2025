# =========================================
# services/detector/api_endpoint.txt
# Tài liệu endpoint Detector (copy dùng nhanh cho QA/DevOps)
# =========================================

# ====== BASE URL ======
# Localhost : http://localhost:8100
# LAN       : http://<HOST_IP>:8100
# Health    : http://<BASE>/healthz

# I) SỨC KHOẺ DỊCH VỤ
# --------------------
# [GET] /healthz
# 200 -> {"status":"ok"}

# II) ẢNH XỬ LÝ (JPEG)
# ---------------------
# [GET] /image?cart_id=<int>
# - Trả JPEG khung hình MỚI NHẤT đã được vẽ bbox/nhãn/FPS.
# - Header: Cache-Control: no-store
# - 200 -> image/jpeg
# - 404 -> chưa có ảnh cho cart_id (ví dụ camera chưa sẵn sàng)
#
# Ví dụ:
#   curl -o latest.jpg "http://localhost:8100/image?cart_id=142"
#   # Trên LAN:
#   curl -o latest.jpg "http://192.168.1.50:8100/image?cart_id=142"

# III) TỒN KHO PHÁT HIỆN (INVENTORY)
# -----------------------------------
# [GET] /inventory?cart_id=<int>
# - Trả JSON hiện trạng nhận diện theo cart: list {product_id, quantity}.
# - Cập nhật mỗi chu kỳ detect (mặc định 7 khung).
# - 200 -> {
#            "cart_id": 142,
#            "updated_at": "2025-08-20T09:30:01.234567+00:00",
#            "items": [
#              {"product_id": 6, "quantity": 1},
#              {"product_id": 1, "quantity": 2}
#            ]
#          }
#
# Ví dụ:
#   curl "http://localhost:8100/inventory?cart_id=142"
#   curl "http://192.168.1.50:8100/inventory?cart_id=142"

# IV) CÁCH TRUY CẬP & LẤY DỮ LIỆU
# --------------------------------
# A) Trình duyệt (GET)
#    - http://localhost:8100/healthz
#    - http://localhost:8100/image?cart_id=142
#    - http://localhost:8100/inventory?cart_id=142
#
# B) cURL nhanh (bash)
#    - Health:
#        curl http://localhost:8100/healthz
#    - Tải ảnh:
#        curl -o f.jpg "http://localhost:8100/image?cart_id=142"
#    - Lấy inventory:
#        curl "http://localhost:8100/inventory?cart_id=142"
#
# C) cURL nhanh (PowerShell/Windows - dùng ^ xuống dòng)
#    curl "http://localhost:8100/inventory?cart_id=142"
#
# D) Từ máy khác cùng mạng (LAN)
#    - Dùng IP máy chạy detector: http://<HOST_IP>:8100/...
#    - Nếu không truy cập được: mở firewall cổng 8100 (TCP) trên máy chạy dịch vụ và kiểm tra port mapping Docker.

# V) MÃ LỖI PHỔ BIẾN
# ------------------
# - 200 OK                : thành công
# - 404 Not Found         : /image chưa có khung hình cho cart, kiểm tra stream/camera
# - 500 Internal Server Error: lỗi nội bộ (xem log container)

# VI) GHI CHÚ TRIỂN KHAI
# ----------------------
# - Port listen: 8100 trong container; map ra host "8100:8100".
# - MODEL_PATH: có thể trỏ tới model khác qua ENV (vd bind mount models/).
# - CARTS: chỉnh trong config.py (cart_id, source); deploy nhiều camera -> thêm dòng trong danh sách.
# - Bảo mật: dịch vụ cấp dữ liệu thô trong LAN; nếu public, đặt reverse proxy + TLS; hạn chế truy cập theo IP/VPN.
