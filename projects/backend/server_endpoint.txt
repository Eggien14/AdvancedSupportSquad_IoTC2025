### 🛒 2. Shopping Cart Management (6 endpoints)

#### GET /carts
**Purpose**: Retrieve all active shopping carts with filtering options
**URL**: `http://localhost:8136/carts`
**Method**: GET
**Authentication**: None (public access)
**Query Parameters**:
- `skip` (int, optional): Number of records to skip (default: 0)
- `limit` (int, optional): Maximum records to return (default: 100)
- `status` (string, optional): Filter by cart status ("active", "completed", "cancelled")

**Response Example**:
```json
{
  "carts": [
    {
      "cart_id": 1,
      "status": "active",
      "created_at": "2024-09-13T09:15:30Z",
      "updated_at": "2024-09-13T10:20:15Z",
      "total_items": 3,
      "total_amount": 127.50,
      "items": [
        {
          "item_id": 1,
          "product_name": "Apple iPhone 15",
          "quantity": 1,
          "unit_price": 999.00,
          "total_price": 999.00
        }
      ]
    }
  ],
  "total_count": 15,
  "has_next": true
}
```

#### POST /carts
**Purpose**: Create a new shopping cart
**URL**: `http://localhost:8136/carts`
**Method**: POST
**Content-Type**: application/json

**Request Body**:
```json
{
  "cart_name": "Customer Cart #1",
  "initial_items": [
    {
      "product_id": 101,
      "quantity": 2
    }
  ]
}
```

**Response Example**:
```json
{
  "cart_id": 1,
  "status": "active",
  "created_at": "2024-09-13T10:30:45Z",
  "message": "Cart created successfully"
}
```

#### GET /carts/{cart_id}
**Purpose**: Retrieve specific cart details by ID
**URL**: `http://localhost:8136/carts/{cart_id}`
**Method**: GET
**Path Parameters**:
- `cart_id` (int): Unique cart identifier

**Response Example**:
```json
{
  "cart_id": 1,
  "status": "active",
  "created_at": "2024-09-13T09:15:30Z",
  "updated_at": "2024-09-13T10:20:15Z",
  "items": [
    {
      "item_id": 1,
      "product_id": 101,
      "product_name": "Apple iPhone 15",
      "quantity": 1,
      "unit_price": 999.00,
      "total_price": 999.00,
      "added_at": "2024-09-13T09:15:30Z"
    }
  ],
  "total_items": 1,
  "total_amount": 999.00
}
```

#### PUT /carts/{cart_id}
**Purpose**: Complete cart update with multiple operation modes
**URL**: `http://localhost:8136/carts/{cart_id}`
**Method**: PUT
**Content-Type**: application/json

**Advanced Update Modes**:

1. **Replace Mode** (Complete replacement):
```json
{
  "mode": "replace",
  "items": [
    {"product_id": 101, "quantity": 3},
    {"product_id": 102, "quantity": 1}
  ]
}
```

2. **Merge Mode** (Add/update items, keep existing):
```json
{
  "mode": "merge",
  "items": [
    {"product_id": 103, "quantity": 2}
  ]
}
```

3. **Delta Mode** (Increment/decrement quantities):
```json
{
  "mode": "delta",
  "changes": [
    {"product_id": 101, "quantity_change": +2},
    {"product_id": 102, "quantity_change": -1}
  ]
}
```

#### DELETE /carts/{cart_id}
**Purpose**: Delete/cancel a shopping cart
**URL**: `http://localhost:8136/carts/{cart_id}`
**Method**: DELETE

**Response Example**:
```json
{
  "message": "Cart deleted successfully",
  "cart_id": 1,
  "deleted_at": "2024-09-13T10:30:45Z"
}
```

#### POST /carts/{cart_id}/checkout
**Purpose**: Process cart checkout and payment
**URL**: `http://localhost:8136/carts/{cart_id}/checkout`
**Method**: POST
**Content-Type**: application/json

**Request Body**:
```json
{
  "payment_method": "credit_card",
  "customer_info": {
    "name": "John Doe",
    "email": "john@example.com",
    "phone": "+1234567890"
  },
  "shipping_address": {
    "street": "123 Main St",
    "city": "Anytown",
    "zip": "12345"
  }
}
```

**Response Example**:
```json
{
  "order_id": "ORD-2024-001",
  "cart_id": 1,
  "status": "completed",
  "total_amount": 999.00,
  "payment_status": "paid",
  "estimated_delivery": "2024-09-15T00:00:00Z",
  "tracking_number": "TRK123456789"
}
```

### 📦 3. Product Management (8 endpoints)

#### GET /products
**Purpose**: Retrieve product catalog with advanced filtering
**URL**: `http://localhost:8136/products`
**Method**: GET
**Query Parameters**:
- `skip` (int): Pagination offset (default: 0)
- `limit` (int): Records per page (default: 100)
- `category` (string): Filter by product category
- `search` (string): Text search in name/description
- `min_price` (float): Minimum price filter
- `max_price` (float): Maximum price filter
- `in_stock` (bool): Filter by availability

**Example URLs**:
- All products: `/products`
- Electronics only: `/products?category=electronics`
- Price range: `/products?min_price=100&max_price=500`
- Search: `/products?search=iphone&in_stock=true`

#### GET /products/{product_id}

**Purpose**: Detect objects in uploaded image
**URL**: `http://localhost:8100/image`

**Request**: Upload image file as form data
**Form Field**: `file` (required)

**Response Example**:

      "confidence": 0.85,
      "bbox": {
        "x1": 100,

    "height": 480,
    "format": "JPEG"

**Maximum File Size**: 10MB
